# DS471 Machine Learning Project
## Breast Cancer Classification — UCI Wisconsin (Diagnostic) Dataset

---
## 📖 Project Overview

This repository contains the complete implementation of the **DS471 Machine Learning** course project. The goal is to build, tune, and compare several machine learning models — including a mandatory Neural Network — to classify breast tumors as **Malignant (1)** or **Benign (0)** based on 30 numerical features extracted from cell nuclei images.

The project follows the five required stages:

| Stage | Description | Status |
|-------|-------------|--------|
| 1 | Data Cleaning, Preparation and Exploration | Done |
| 2 | Data Splitting | Done |
| 3 | Model Selection and Development | Done |
| 4 | Model Training and Hyperparameter Optimization | Done |
| 5 | Model Final Evaluation and Comparison | Done |
